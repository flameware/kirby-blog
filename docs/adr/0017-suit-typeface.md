# ADR-0017: 글꼴은 SUIT 하나이고, 직접 올려서 내려준다

- **상태:** 채택
- **날짜:** 2026-09-21
- **관련:** [ADR-0008](0008-type-scale.md), [ADR-0010](0010-asset-cache-busting.md), [ADR-0013](0013-cache-control-tiers.md), [ADR-0016](0016-static-build.md)

## 맥락

사이트 전체가 Gowun Batang(명조) 하나를 썼다. 세리프를 쓰는 해외 블로그를 기준으로 삼아 고른 것이었는데, 시간이 지나면서 화면이 **시각적으로 떨어지지 않는다** — 또렷하게 서 있지 않고 흐릿하게 퍼진다는 인상이 쌓였다.

글꼴은 한 줄(`--text-font`)만 바꾸면 되지만, 느낌을 말로 비교하기는 어렵다. 그래서 먼저 버리는 코드로 글꼴 전환기를 따로 브랜치에 만들어 실제 화면 위에서 비교했다. 제목 글꼴과 본문 글꼴, 굵기, 본문 크기 배율, 행간을 바꿔 가며 홈·목록·글 세 편·소개 화면을 봤다.

후보는 아홉이었다.

- 명조: Gowun Batang(기준), Noto Serif KR, MaruBuri, RIDIBatang, Nanum Myeongjo
- 고딕: Pretendard, SUIT, IBM Plex Sans KR, Noto Sans KR

## 결정

**제목·소제목·본문 모두 SUIT 하나를 쓴다. 굵기는 400과 700이고, 크기 배율과 행간(1.8)은 그대로다.** 바뀐 것은 글꼴뿐이다. 제목과 본문에 다른 글꼴을 짝짓는 조합도 비교했지만, 한 글꼴로 통일한 쪽을 택했다.

```css
--text-font: 'SUIT', -apple-system, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif;
```

**파일은 직접 올려서 같은 도메인에서 내려준다.** 고정 굵기 `woff2` 두 개(Regular 168KB, Bold 171KB)를 `assets/fonts/suit-2.0.5/`에 두고 `@font-face`는 `index.css`에 쓴다. Regular는 `header.php`에서 preload한다. `_headers`에서 `/assets/fonts/*`에 1년 `immutable`을 건다.

## 근거

### 왜 SUIT인가

- **명조 계열은 모두 탈락했다.** Noto Serif KR, MaruBuri, RIDIBatang, Nanum Myeongjo는 저마다 다르지만 결국 Gowun Batang의 연장선으로 읽혔다. 바꾸려는 것이 명조라는 방향 자체였다.
- **Pretendard가 아니라 SUIT인 이유는 라틴 글자다.** 본문에 영문(밴드명, F1, NBA, 도구 이름)이 자주 섞인다. Pretendard의 라틴은 Inter를 바탕으로 한 익숙한 형태여서 흔한 느낌이다. SUIT의 라틴은 덜 흔해서 신선하게 느껴졌다.
- 라틴 전용 글꼴을 따로 섞는 안은 이번에 보지 않았다. 한글 글꼴에 딸린 라틴이 선택의 결정적 이유였으므로 섞을 이유가 없어졌다.

### 왜 직접 올리는가

- **SUIT는 Google Fonts에 없다.** 기존처럼 Google이 글자 범위별로 잘라 필요한 조각만 내려주는 방식을 쓸 수 없다. 남는 선택지는 jsDelivr 같은 공용 CDN이나 직접 올리기다.
- **남의 서버에 기대지 않는다.** ADR-0010이 normalize.css를 두고 내린 판단과 같다 — 타입 스케일이 남의 서버가 살아 있는지에 기대고 있을 이유가 없다. 같은 도메인이면 연결을 한 번 더 맺을 필요도 없다.
- **정적 빌드가 이미 이것을 받쳐 준다.** `build-static.php`가 `assets/`를 통째로 `dist/`에 옮기므로 따로 빌드 단계를 둘 필요가 없다(ADR-0016).
- **가변 굵기 파일(625KB)이 아니라 고정 굵기 두 개(합계 339KB)다.** 이 사이트가 쓰는 굵기는 400과 700 둘뿐이다.
- 라이선스는 SIL OFL 1.1이라 직접 배포할 수 있다. 라이선스 원문을 파일 옆(`OFL.txt`)에 함께 둔다.

### 캐시와 로딩

- **경로의 버전이 캐시 무효화다.** 글꼴은 CSS처럼 `?v=`를 붙여 주는 헬퍼(ADR-0010)를 거치지 않는다. 그래서 파일 이름이 아니라 **폴더 이름에 버전을 박았다.** 이렇게 하면 ADR-0013의 "주소가 바뀌면 내용이 바뀐다" 계층에 넣을 수 있다. 파일을 바꿀 때는 덮어쓰지 않고 `suit-<새 버전>/` 폴더를 새로 만든다.
- **이전의 `<style>@import</style>`는 없앴다.** HTML → Google CSS → 글꼴 파일로 요청이 한 단계씩 늦게 시작하는 구조였다. 이제 preload가 CSS와 나란히 Regular를 받기 시작한다. Bold는 preload하지 않는다. 두 개를 다 당기면 첫 화면 CSS와 대역폭을 다투기 때문이다.
- **대체 글꼴은 고딕이다.** `font-display: swap`이라 파일이 오기 전에 잠깐 대체 글꼴이 보인다. 명조에서 고딕으로 바뀌는 것보다 고딕끼리 바뀌는 쪽이 덜 튄다.

## 결과

- 첫 방문에서 글꼴 전송량이 Google이 잘라 준 조각들에서 최대 339KB로 바뀐다. 두 번째 방문부터는 1년 캐시다.
- ADR-0008의 "세리프 한글 본문의 통상 하한(15~17px)"은 당시 글꼴을 전제로 한 말이다. 눈금(`--fluid`와 배수)은 그대로 두었다. 전환기에서 본문 크기 배율 1.0이 가장 나았기 때문이다.
- 주석으로 남아 있던 Gowun Dodum + Instrument Sans 불러오기도 함께 지웠다.
- 비교에 쓴 전환기는 `main`에 들어오지 않았다. 비교가 끝나 브랜치(`prototype/fonts`)도 지웠다. 다시 비교할 일이 생기면 새로 만든다.
