# ADR-0001: 애널리틱스는 GoatCounter를 쓴다 (GA4 아님)

- **상태:** 채택
- **날짜:** 2026-08-04

## 맥락

"예전에 Google Analytics를 붙여둔 것 같다"는 기억에서 출발했으나, 확인 결과 **설치된 적이 없었다**:

- 작업 트리 전체(`site/`, `assets/`, `index.php`, `.htaccess`, 설정 파일)에서 `gtag` / `googletagmanager` / `google-analytics` / `G-` / `UA-` 검색 결과 0건
- `git log --all -S "gtag"`, `-S "googletagmanager"` 모두 0건 — 넣었다 지운 흔적도 없음
- 운영 HTML(`https://massivevoid.com/`, HTTP 200) 응답에도 없음. `<head>`가 로컬 `header.php`와 일치하고 `<script>`는 모바일 메뉴 인라인 하나뿐

GA 콘솔에 속성만 만들어두고 태그 설치를 안 한 상태였을 가능성이 높다.

계측으로 답하고 싶은 질문은 두 개로 좁혀졌다:

1. **어떤 글이 읽히는가** — 다음에 뭘 쓸지 결정에 직접 쓰임
2. **사람이 오긴 오는가**

전환, 이벤트, 퍼널, 잠재고객, 광고 연동은 필요 없다.

## 결정

**GoatCounter**(호스팅, 사이트 코드 `massivevoid`)를 쓴다. GA4는 채택하지 않는다.

스크립트는 **운영 도메인에서만** 출력한다. 사이트 코드를 `site/config/config.massivevoid.com.php`의 `analytics.goatcounter` 옵션에 두고, `site/snippets/header.php`가 그 옵션이 있을 때만 태그를 렌더한다. 이 저장소가 이미 `panel => false`에 쓰고 있는 호스트별 설정 패턴과 동일하다.

방문자 고지는 `about` 페이지 마지막 블록 두 문장으로 갈음한다.

## 근거

**GA4를 버린 이유:**

- 쿠키를 심는다 → 한국 개인정보보호법·EU 방문자 기준 동의 배너 문제가 따라온다. 개인 블로그에 배너를 다는 건 비용 대비 손해
- 애드블로커가 `googletagmanager.com`을 가장 먼저 차단한다. 독자층이 기술 성향(Claude Code, 개발, F1)이라 실측 손실이 크고, 하필 "사람이 오긴 오는가"라는 질문의 답이 체계적으로 축소된다
- "인기 글 순위"를 보려면 `보고서 → 참여도 → 페이지 및 화면`까지 들어가야 한다. 안 보게 된다
- 필요 없다고 정리한 기능들이 GA4의 존재 이유 전부다 — 요구사항 대비 과잉

**GoatCounter를 고른 이유:** 쿠키 없음 → 배너 불필요, 대시보드 첫 화면이 곧 글별 조회수 순위 + 방문자 수, 개인 사이트 무료, 운영 부담 없음. 요구 두 개에 정확히 대응하고 그 이상을 하지 않는다.

**탈락한 대안:**

- **서버 로그 분석(GoAccess)** — Apache `kirby_access.log`가 이미 combined 포맷으로 쌓이고 있어 코드 변경 0으로 가능하다. 그러나 봇 노이즈가 크고 사람/크롤러 구분이 부정확해, 하필 주요 목적인 "글별 순위"가 오염된다. 또 조회하려면 ssh가 필요해 실제로 안 보게 된다
- **Plausible / Umami 등 유료 SaaS** — 방향은 같으나 개인 블로그 규모에 월 비용이 과잉

**운영 전용으로 둔 이유:** 글 17편에 트래픽이 크지 않아, `composer start` 로컬 미리보기가 집계에 섞이면 오염이 신호보다 커질 수 있다. GoatCounter의 `count.js`가 localhost를 자동 제외하는지는 공식 문서에 명시돼 있지 않아, 도구 동작에 기대지 않고 설정 계층에서 분리했다.

## 결과

- 방문자에게 동의 배너를 띄우지 않는다. 이 전제가 깨지는 도구로 바꾸려면 이 ADR을 다시 열어야 한다
- 애드블로커 사용자 일부는 여전히 집계되지 않는다. GoatCounter가 GA보다 덜 차단될 뿐 면역은 아니다 — 숫자는 하한선으로 읽는다
- 검색어별 노출·클릭은 답할 수 없다. 그건 Google Search Console의 영역이고 이번 범위 밖으로 뒀다

## 2026-09-23 갱신 — 숫자를 실측했다

운영이 Cloudflare Pages로 옮겨 간 뒤(ADR-0016), Cloudflare 도메인 개요의 "Unique Visitors"가 주 1.11k인데 GoatCounter는 같은 주 126 방문으로 **열 배 가까이 갈렸다.** 어느 쪽을 믿을 것인가를 확인했다. 아래는 그날 잰 값이다.

**결론부터: 두 숫자는 다른 것을 센다. 독자 수를 묻는 질문에는 GoatCounter가 맞다.**

### 잰 방법과 값

**① 주입 테스트 — 답을 아는 방문을 넣고 몇 개가 잡히는지 셌다.** 조용한 글 다섯 편에 조건별로 하나씩.

| 조건 | 주입 | 잡힘 |
|---|---|---|
| 데스크톱·애드블로커 끔·시크릿 | 1 | 1 |
| 데스크톱·**애드블로커 켬** | 1 | 1 |
| iOS Safari | 1 | 1 |
| 같은 브라우저로 9분 뒤 재방문 | 2 | **1** (세션 합산) |
| 화면이 뜨기 전 3초 내 이탈 | 1 | **0** |

**정상 체류 방문은 5/5, 놓친 것은 조기 이탈 하나뿐이다.**

**② 분포 점검 — 봇이 사람으로 섞였는지.** 주간 126건에서 Linux 2%, Windows 60%/macOS 22%/iOS 13%, 한국 71%. 크롤러가 섞였다면 Linux가 압도한다. **오염 없음.**

**③ 엣지 대조 — 그러면 Cloudflare의 1.11k는 무엇인가.** 24시간 총 요청 4,170건 중 **한국이 349건으로 4위**다. 1~3위는 미국 1,352 · 대만 880 · 네덜란드 386 — 사람이 사는 곳이 아니라 데이터센터가 있는 곳의 순위다. 같은 날 GoatCounter는 24 방문이었다. **엣지 트래픽의 대부분이 기계다.**

### 위 본문에서 바뀌는 것

- **"애드블로커 사용자 일부는 여전히 집계되지 않는다"** — 적어도 필자가 쓰는 차단기는 `gc.zgo.at`을 막지 않는다. 표본이 하나라 일반화하지 않지만, **Cloudflare와의 열 배 차이를 애드블로커로 설명하려던 가설은 기각됐다.** 차이는 봇이다.
- **"`count.js`가 localhost를 자동 제외하는지 문서에 명시돼 있지 않다"** — 소스에 있다. `count.js`는 `localhost`·`127.`·`10.`·`172.16~31.`·`192.168.`·`file:`를 스스로 건너뛴다. 그래도 **운영 전용 렌더링은 유지한다.** 도구의 내부 동작은 예고 없이 바뀌고, 정적 빌드에서는 태그가 빌드 시점에 박히므로 애초에 다른 층의 방어다.
- **진짜 누수 경로는 조기 이탈이다.** `count.js`가 `async`라 로드 전에 떠나면 사라진다. 무작위 노이즈가 아니라 방향이 정해진 편향이다 — **훑고 나가는 유입일수록 덜 잡히고, 읽으러 온 사람일수록 잘 잡힌다.** 이 ADR이 묻는 "어떤 글이 읽히는가"에는 오히려 맞는 편향이므로 고치지 않는다.

### 함께 한 조치

- **필자 본인의 방문을 뺐다.** 위 주입 테스트가 보여준 것은 **필자의 방문이 하나도 빠짐없이 집계된다**는 것과, 하루 20여 건 규모에서는 **여섯 번만 들어가도 그날의 4분의 1이 된다**는 것이다(테스트로 만든 6건이 그날 24건 중 6건이었다 — 평소 필자가 자기 사이트를 얼마나 여는지는 재지 않았다). 글을 올리고 운영에서 확인하는 흐름 탓에 새 글일수록 본인 방문이 붙으므로, 최신 글이 항상 인기 있어 보이는 **체계적 편향**이 생길 수 있다. 쓰는 브라우저마다 `https://massivevoid.com/#toggle-goatcounter`를 한 번 열어 `localStorage`에 표식을 심었다. 토글이므로 **다시 열면 풀린다.** 시크릿 창과 사이트 데이터 삭제 뒤에는 남지 않는다.
- **`CONTEXT.md`에 `계측` 절을 만들었다.** 이 혼란의 뿌리가 "방문·순방문자·요청"을 모두 "방문자"로 부른 데 있었다.

### 하지 않기로 한 것

**Cloudflare Web Analytics를 2주 병행해 대조하는 실험.** 설계까지 했다가 접었다. 그것이 답할 수 있는 건 "독자 모집단의 차단율"뿐인데, 차단도 오염도 반증된 뒤라 **어떤 결정도 그 숫자로 달라지지 않는다.** 대시보드 토글로 켜면 저장소에 없는 스크립트가 모든 페이지에 실려 나가고(ADR-0015가 세운 문턱), 그 값을 치를 이유가 사라졌다.

### 남은 것

GoatCounter 주간 통계의 **미국 23%(29건)**는 아직 설명되지 않았다. 재외 독자·VPN·UA를 위장한 헤드리스 브라우저가 후보다. 판별을 위해 GoatCounter의 Languages 수집을 켰다 — 미국발 방문이 `ko`를 보내면 사람 쪽이다.
- 로컬에서는 태그가 아예 렌더되지 않으므로, 계측 동작 검증은 운영 배포 후에만 가능하다
